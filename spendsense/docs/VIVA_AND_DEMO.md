# Demonstration and evaluation guide

Start the app with run.bat. My finances starts empty; use only your own consented records. Household sample contains the real historical INR reference and must be described as one household, without converting to PKR or presenting it as a student population. No automatic generated sample is available.

Show recorded category proportions as descriptive summaries. Do not assign a research cluster to the user. Open eval/spending_mix_v1/REPORT.md separately to explain fixed K, entity weighting, temporal debit shares, stability and source limitations. The research clusters are not deployed.

Explain every wallet snapshot, commitment and intake confirmation using the actual records. Accounting fixes and the numerical advice guard must pass before mobile/APK packaging. Do not promise trained personal forecasts, physical-phone verification or background reminders without evidence.

Berka's completed frozen report can be reviewed from saved artifacts only. Do not rerun its test evaluator or deploy its models. The earlier-month low-balance event and continuous month-end balance ratio are different outcomes.

Pending evidence: P0 accounting regression checks, adversarial affordability checks, chronological personalization learning curves, common untouched categorizer benchmark and end-to-end hybrid survival errors. See the ordered work log for completion status.
